# Проверки статического лендинга

Окружение проверки: Linux, Node.js 26.8.2, Chromium, Next.js 16.4.5. Контент обновлён 5 ноября 2026 года.

## Изменения

- Встроены шесть услуг и 11 этапов обработки. Антикор — от 18 000 ₽ во всех местах, включая SEO и schema; полировка по-прежнему от 5 000 ₽. Шумоизоляция — стоимость по запросу, без вымышленной числовой цены.
- Используются десять фотографий заказчика, включая фото шумоизоляции `Pasted image (8).png`. Иконок нет.
- Новые фото размещены непосредственно в карточках услуг «Полировка» и «Полировка фар», из галереи эти два изображения убраны.
- Отдельная секция до/после использует цельные исходные сравнения; направления до/после указаны корректно для каждого изображения.
- Галерея и сравнения открываются в доступном модальном просмотре с клавиатурным управлением. 13 отзывов воспроизведены текстом: четыре из Яндекс Карт и девять с новых скриншотов Avito; исходные авторы, даты, оценки и источники сохранены. Отзыв Кристины отмечен как фрагмент, отзыв Дмитрия — как покупка ASIC, не автоуслуга.
- Телефон, Avito и VK — прямые ссылки. Форм, API, базы данных, webhook, сбора заявок и backend нет.
- Название, адрес и совпадение телефона проверены по карточке Яндекс Карт. Четыре отзыва Яндекс Карт сверены с публичной страницей организации; девять новых — с переданными скриншотами Avito.
- FAQ удалён. Контакты представлены одним разделом; footer содержит только бренд, навигацию и copyright.
- Процесс — три статические группы с сохранением всех 11 этапов. Закреплённой фотографии, вложенных скроллеров и перехвата прокрутки нет.
- По просьбе убрать атрибуцию Icons8 удалены все их ресурсы, компонент и favicon. Требования бесплатной лицензии не обходятся.

## Команды

- `npm run lint` — без ошибок и предупреждений.
- `npm run build` — успешный статический экспорт в `out/`; динамических серверных маршрутов нет.
- `npm run typecheck` — без ошибок.
- `npm test` — **18 / 18 тестов успешно**, 38,8 с. Проверены адаптивность, мобильное меню, галерея, до/после, все 13 отзывов и их источники, шесть услуг, цена антикора 18 000 ₽ во всех блоках и метаданных, фото шумоизоляции в услуге и отсутствие вымышленной цены. Дополнительно проверены честная маркировка фрагмента и покупки ASIC, 11 этапов, прямые контакты, отсутствие FAQ/дублей контактов/Icons8, работа без JavaScript, статический экспорт и естественная прокрутка.
- `npm audit --omit=dev` — 0 уязвимостей. В dev-цепочке ESLint/minimatch остаются 16 moderate; несовместимый `audit fix --force` не применялся. Эти инструменты не нужны на статическом хостинге.

## Изображения и браузер

- Проверены 320, 375, 430, 768, 1024, 1440, 1920 px: нет горизонтального скролла, все изображения загружаются, один H1, ошибок JavaScript нет.
- Скриншоты всех ширин: `test-results/screenshots/`.
- Дополнительно визуально просмотрены новая структура процесса, текстовые отзывы на desktop/mobile и единый раздел контактов.
- Исходные скриншоты отзывов сохранены как источники. На страницу они не загружаются; даты без года не дополнены вымышленным годом.
- Фото оптимизированы заранее; `next/image` работает без серверного оптимизатора. Оригиналы не изменены.
- API-запросов при работе страницы нет; `/api/leads` и удалённая страница проекта политики возвращают 404.
- В DOM нет SVG-пиктограмм и обращений к ресурсам Icons8, включая favicon.

## Перед размещением

- Указать реальный домен в `NEXT_PUBLIC_SITE_URL` и пересобрать для canonical/OG/sitemap.
- Разместить содержимое `out/` на статическом хостинге, настроить его страницу 404 и заголовки безопасности согласно README.
- При необходимости подтвердить актуальность исходной ссылки VK: ссылка в Яндекс Картах отличается, поэтому без согласования она не заменялась.
- Оставшиеся вопросы прав на материалы и графика работы перечислены в `CONTENT_TODO.md`; на странице нет служебных предупреждений.

Lighthouse, полевые Core Web Vitals, Safari, Firefox и физические мобильные устройства в эти проверки не входили. Реальные звонки и сообщения заказчику не отправлялись.
