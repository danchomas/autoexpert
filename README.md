# Автоэксперт · Белгород

Статический лендинг: Next.js App Router, React, TypeScript и Tailwind CSS. Услуги и цены, технология обработки, реальные фотографии, сравнения до/после и текстовые отзывы с Яндекс Карт. Единственный блок контактов ведёт напрямую в Avito, VK и на `tel:+79040920381`. FAQ отсутствует.

**Форм, API, базы данных, обработчиков заявок и backend нет.** Для размещения нужен только статический хостинг.

## Разработка и сборка

Node.js 20.11+.

```sh
npm install
npm run dev
```

Разработка: http://localhost:3100.

```sh
npm run build
npm start
```

`npm run build` создаёт готовую папку **`out/`**. Загрузите её содержимое на обычный статический хостинг. `npm start` — только локальный просмотр этих файлов встроенным файловым HTTP-сервером; на хостинге Node.js не нужен. При необходимости другой порт: `PORT=3200 npm start`.

## Контент

- `src/data/company.ts` — компания, телефон, внешние ссылки, все услуги и цены, 11 этапов в трёх группах, фотографии и отзывы.
- `public/images/` — предоставленные заказчиком оригиналы. Не удаляются и не изменяются.
- `public/images/optimized/` — WebP-копии фотографий для сайта. Все встроенные подписи и водяные знаки сохранены. Скриншоты отзывов остаются исходным материалом, но не выводятся на страницу.
- `npm run images` — повторное создание WebP-копий из оригиналов.
- `src/components/sections/` — секции лендинга.
- `src/components/ui/photo-viewer.tsx` — просмотр работ и сравнений с клавиатурным управлением.
- `src/app/globals.css` — токены и адаптивные стили.

Сравнения до/после опубликованы как предоставленные цельные изображения. Они не превращаются в искусственный слайдер из несовпадающих ракурсов. Фотографии `полировка.png` и `полировка-фар.png` находятся в соответствующих карточках услуг, не в галерее.

Процесс — три статические группы: подготовка, нанесение защиты и завершение. Все 11 этапов видны сразу, без sticky, внутренних скроллеров и перехвата прокрутки.

Отзывы свёрстаны текстом: сохранены исходные авторы, даты, оценки, статус закрепления и формулировки. Год не дописывается, если его не было в источнике. Оценки показаны текстом, без самодельных звёзд и пиктограмм.

Название и адрес подтверждены карточкой Яндекс Карт с совпадающим телефоном. Услуги, цены и технология взяты из сообщения заказчика. Рейтинг и сроки гарантии не придуманы.

Антикор — **от 18 000 ₽**; цена хранится в данных и используется также в hero, прайсе, SEO и schema. Для новой услуги «Шумоизоляция авто» цена не предоставлена: отображается «Стоимость по запросу», в schema числовой цены нет. Её фотография `Pasted image (8).png` находится в секции услуг.

Отзывы: четыре из Яндекс Карт и девять с предоставленных скриншотов Avito, с раздельными ссылками на источники. Обрезанный отзыв Кристины отмечен как фрагмент. Для отзыва Дмитрия сохранён контекст покупки ASIC, чтобы не приписывать его автоуслуге.

## Домен и SEO

Укажите `NEXT_PUBLIC_SITE_URL` в `.env.local` перед финальной сборкой для canonical, Open Graph URL и sitemap. Это единственная переменная, секреты не нужны. Страница открыта для индексации. Домен не подставляется вымышленный.

Веб-шрифты и фото локальные. Иконки больше не используются: бесплатные Icons8 удалены вместе с требовавшейся атрибуцией. Внешние карты, аналитика и виджеты не встраиваются. Заголовки безопасности задаются на статическом хостинге: `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`.
